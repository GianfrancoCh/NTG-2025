# Proyecto **Comanda App**

Aplicación móvil integral para la gestión de restaurantes: registro de usuarios, pedidos en mesa y delivery, generación de códigos QR, encuestas y notificaciones _push_.

---

## 🌳 Ramas principales

| Rama         | Propósito                              |
| ------------ | -------------------------------------- |
| `main`       | Rama de producción estable             |
| `tony`       | Desarrollo de **Antonio Aguirre**      |
| `gianfranco` | Desarrollo de **Gianfranco Chiarizia** |

> ℹ️ Añade o cambia las ramas según las que utilice tu repositorio.
